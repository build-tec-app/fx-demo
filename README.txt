FXデモトレード（スマホにインストールしてオフラインで使う版）

このフォルダをそのままHTTPSのサイトに置くと、スマホのホーム画面に追加できます。
一度開けば、以後はネットなしでも起動します。

いちばん簡単な置き方：
1. https://app.netlify.com/drop を開く
2. このフォルダ（pwa）をドラッグ＆ドロップ
3. 表示されたURLをスマホで開く
   iPhone：Safariの共有ボタン →「ホーム画面に追加」
   Android：Chromeのメニュー →「アプリをインストール」または「ホーム画面に追加」

GitHub Pagesに置いても同じように使えます。
データ（残高・建玉・履歴）はスマホの中だけに保存されます。
